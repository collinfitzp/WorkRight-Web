# Images to add

This folder is currently empty except for a placeholder favicon. Add these
files when you have real assets, then update the matching reference in
`index.html`:

- `favicon.svg` (or `favicon.ico`) — replace with your real logo mark.
- `og-preview.jpg` — a 1200×630 image used when the site is shared on
  social media (referenced by the `og:image` tag in `index.html`).
- `example-1.jpg`, `example-2.jpg`, `example-3.jpg` — real screenshots
  of your Framer templates, to replace the "Screenshot placeholder"
  boxes in the Examples section. Once added, swap each
  `<div class="example-thumb">...</div>` for an `<img>` tag, e.g.:

  ```html
  <img src="assets/images/example-1.jpg" alt="Homepage of the Modern Home Services template">
  ```

You can delete this file once your real images are in place.
